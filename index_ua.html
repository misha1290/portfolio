Beauty Lab

Vanilla JS • Tailwind CSS • Fetch API

Преміальний, двомовний (RU/DE) лендінг, розроблений для естетичного центру в Німеччині. Проєкт має динамічний рендеринг DOM, анімації при скролі та безсерверну систему збору лідів, інтегровану з Telegram.

Ключові особливості:

  • Безсерверна відправка форм: Маршрутизація запитів на бронювання до Telegram-бота через Google Apps Script в обхід обмежень CORS preflight.
  • Збереження стану (UX): Використання localStorage для тимчасового збереження даних, введених користувачем, щоб запобігти їх втраті при випадковому перезавантаженні сторінки.
  • Двомовна архітектура: Динамічне перемикання мов (Російська/Німецька) реалізоване через кастомний JS-словник та обхід DOM, без перезавантаження сторінки.
  • Продуктивність: Стилізовано виключно за допомогою Tailwind CSS, анімації працюють через нативний API IntersectionObserver для оптимальної швидкості рендерингу.
telegram-api.js 
// Asynchronous lead capture & CORS handling
        const GOOGLE_APP_URL = 'https://script.google.com/macros/s/.../exec'; 

        async function sendToTelegram(message, inputIdsToClear) {
            try {
                const response = await fetch(GOOGLE_APP_URL, {
                    method: 'POST',
                    // Using text/plain to avoid CORS preflight issues in Google Script
                    headers: { 'Content-Type': 'text/plain;charset=utf-8' },
                    body: JSON.stringify({ message: message })
                });
                
                const result = await response.json();
                
                if (result.status === 'success') {
                    showSuccessModal();
                    clearFormStorage(inputIdsToClear); // Clears localStorage upon success
                } else {
                    console.error('Server Error:', result.message);
                }
            } catch (error) {
                console.error('Network Error:', error);
            }
        }

Time Sync Manager & Shop

JavaScript (ES6+) • Fetch API • LocalStorage

Вебдодаток із таймером зворотного відліку, синхронізованим з глобальним API часу. Він включає віртуальний магазин, де користувачі можуть купувати або використовувати бонуси, що змінюють час.

Ключові особливості:

  • Синхронізація часу із сервером: Отримання даних UTC в реальному часі з worldtimeapi.org для коригування зсуву клієнтського годинника та запобігання маніпуляціям.
  • Постійне керування станом: Використання localStorage для збереження часу завершення таймера, моментів паузи та інвентарю магазину (наприклад, зупинка часу) між перезавантаженнями браузера.
  • Динамічне оновлення UI: Динамічне обчислення годин, хвилин та секунд, а також очищення інтервалу, коли таймер досягає нуля.
timer-sync.js 
// Fetching real UTC time to prevent client-side cheating
        async function getServerTime() {
        try {
            const response = await fetch("https://worldtimeapi.org/api/ip");
            const data = await response.json();
            return new Date(data.utc_datetime);
        } catch (error) {
            console.error("API Error:", error);
            return new Date(); // fallback: local time
        }
        }

// Handling draggable radio slider and track switching
        draggable.onmousedown = function(event) {
            isDragging = true;
            document.onmousemove = function(event) {
                if (isDragging) {
                    const containerRect = container.getBoundingClientRect();
                    let newLeft = event.clientX - containerRect.left - draggable.offsetWidth / 2;

                    let closestPosition = positions[0];
                    let closestDistance = Math.abs(newLeft - positions[0]);
                    for (let pos of positions) {
                        let distance = Math.abs(newLeft - pos);
                        if (distance < closestDistance) {
                            closestPosition = pos;
                            closestDistance = distance;
                        }
                    }
                    draggable.style.left = closestPosition + 'px';
                }
            };
        };
